# RBS → MapleRise section map

Layout reference: https://rbsland.com/ (home page, read 2026-10-20). Only RBS's **section order, layout pattern and interaction patterns** are reused. No RBS text, images, logos, colours, team photos, quote or brand name appear in this build.

Rows are in page order, top to bottom. The order in `src/App.tsx` follows this table.
